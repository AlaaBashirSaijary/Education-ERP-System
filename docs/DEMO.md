# عرض تجريبي لمدير المدرسة

الهدف: رابط واحد يفتحه مدير المدرسة على هاتفه أو حاسوبه، فيجرّب النظام كاملاً **بنقرة واحدة** دون تسجيل، ثم يتواصل معك لشرائه.
يتحقق ذلك بـ **وضع العرض** (`SCHOOL_DEMO_MODE=true`). لا تفعّله أبداً على قاعدة بيانات فيها بيانات مدرسة حقيقية.

## ماذا يتغيّر في وضع العرض
| | |
|---|---|
| صفحة تعريفية على `/` | مزايا النظام + بطاقات «الدخول كمدير المدرسة / معلم / محاسب / ولي أمر» بنقرة واحدة + زر «تواصل معنا» |
| شريط أصفر في التطبيق | يذكّر أن البيانات وهمية وتُعاد تهيئتها، مع رابط التواصل |
| **إعادة تهيئة تلقائية** | كل `DEMO_RESET_HOURS` ساعات (افتراضي 6) يُمسح كل شيء ويُعاد تحميل بيانات تجريبية جديدة، فلا يتراكم عبث الزوار |
| حسابات العرض مشتركة ومحمية | كلمات مرورها عشوائية؛ لا يمكن تغييرها ولا تعديل هذه الحسابات ولا حذفها، فلا يستطيع زائر أن يقفل الباقين |
| لا رسائل حقيقية | الإشعارات تُسجَّل فقط ولا تصل لأي هاتف، حتى لو ضُبط واتساب في البيئة |
| الأمر `demo:reset` | يرفض العمل إن لم يكن وضع العرض مفعّلاً (حماية لبياناتك الحقيقية) |

## الأسهل: من جهازك بلا استضافة ولا بطاقة
```bash
bash scripts/update.sh                                   # مرة واحدة: يحدّث ويبني
DEMO_WHATSAPP=962791234567 bash scripts/share-demo.sh    # رقمك بالصيغة الدولية بلا +
```
يطبع رابط **HTTPS** عاماً (مثل `https://xxxx.trycloudflare.com`) يفتحه أي شخص من هاتفه. الرابط يعمل **ما دامت النافذة مفتوحة وجهازك متصلاً**، ويتغيّر في كل مرة تشغّله. اضغط `Ctrl+C` لإيقاف المشاركة.
- يستعمل ملف قاعدة بيانات منفصلاً (`database/demo.sqlite`)، فلا يمسّ بياناتك العادية.
- الرابط عبر `cloudflared` إن كان مثبّتاً (`brew install cloudflared`، وأنصح به)، وإلا عبر `ssh` وخدمة localhost.run. هاتان خدمتان مجانيتان من طرف ثالث بلا ضمان استمرار؛ جرّب الرابط قبل الموعد.
- إن ظهرت الصفحة بلا تنسيق أو بطيئة جداً فالسبب غالباً خدمة النفق المجانية (localhost.run)؛ ثبّت `cloudflared` وأعد التشغيل. السكربت يضبط `ASSUME_HTTPS=true` فلا تظهر روابط `http://` داخل صفحة `https://`.
- مناسب لعرض مباشر أمام مدير المدرسة أو لإرسال رابط ليوم واحد. للاستضافة الدائمة استعمل أحد الخيارين أدناه.

## النشر الدائم (اختر واحداً)

### أ) Render: الأسرع، بنقرات قليلة
1. ارفع المستودع إلى حسابك على GitHub (هو هناك بالفعل).
2. في Render: **New ← Blueprint** واختر المستودع والفرع الذي فيه `render.yaml`.
3. سيطلب منك: `DEMO_WHATSAPP` (رقمك بالصيغة الدولية بلا `+`، مثل `962791234567`) و`DEMO_EMAIL` و`APP_URL`. بعد أول نشر ضع في `APP_URL` عنوان الخدمة الذي أعطاك إياه Render (يبدأ بـ `https://`).
4. انتظر البناء (بضع دقائق). سيعمل `demo:reset` تلقائياً عند أول إقلاع ويحمّل البيانات.

> الخطة المجانية في الاستضافات عادةً **تنام عند الخمول**، فيتأخر أول فتح حوالي نصف دقيقة أو أكثر، وقاعدة البيانات المجانية قد تكون محدودة المدة. **راجع الشروط الحالية** قبل أن تعتمد عليها في عرض مهم. لعرض أمام مدير مدرسة أنصح بخطة مدفوعة صغيرة أو الخيار (ب).

### ب) خادم VPS صغير + نطاق خاص (الأفضل لعرض جاد)
نطاق باسمك (مثل `demo.اسم-منتجك.com`)، لا ينام، وشهادة HTTPS تلقائية:
```bash
# على خادم فيه Docker، ونطاق يشير سجل A فيه إلى عنوان الخادم
git clone -b <الفرع> https://github.com/AlaaBashirSaijary/Education-ERP-System.git && cd Education-ERP-System
cp .env.demo.example .env.demo      # عدّل: DOMAIN, APP_URL, DB_PASSWORD, SCHOOL_NAME, DEMO_WHATSAPP...
docker compose --env-file .env.demo up -d --build
```
الخدمات: التطبيق (ويب + الطابور + المجدول)، وPostgreSQL، وCaddy الذي يجلب شهادة HTTPS ويعيد التوجيه.
HTTPS ضروري أيضاً لتثبيت الموقع كتطبيق على الهاتف.

> **لم أبنِ صورة Docker ولا شغّلت هذه الملفات على Render أو على خادم**، لأن بيئة التطوير لا تحتوي Docker ولا لدي حساب استضافة. جرّبت خطوات الإقلاع نفسها في وضع الإنتاج على PostgreSQL (الترحيل، التعبئة التلقائية، المجدول، الدخول بنقرة، شريط العرض)، وتحققت من صحة صياغة الملفين. إن فشل البناء أرسل لي سجلّه.

## متغيرات وضع العرض
| المتغير | المعنى |
|---|---|
| `SCHOOL_DEMO_MODE=true` | يفعّل كل ما سبق |
| `SCHOOL_NAME` | اسم منتجك، يظهر في كل مكان وعلى أيقونة التطبيق |
| `DEMO_WHATSAPP` / `DEMO_EMAIL` | كيف يتواصل معك المهتم (يظهر زر «تواصل معنا») |
| `DEMO_RESET_HOURS` | كل كم ساعة تُعاد تهيئة البيانات |
| `APP_URL` | عنوان الموقع الكامل بـ `https://` |
| `APP_KEY` | اتركه فارغاً في العرض: يُولَّد مفتاح مؤقت عند كل إقلاع |

## قبل أن ترسل الرابط لمدير مدرسة
- ضع اسم منتجك في `SCHOOL_NAME` ورقم واتساب حقيقياً، وجرّب أن زر «تواصل معنا» يفتح محادثة.
- افتح الرابط **من هاتفك** وجرّب الأدوار الأربعة بالعربية، وجرّب «تثبيت التطبيق».
- لا تجعل العرض قبل موعد إعادة التهيئة بدقائق إن كنت ستشاركه شاشتك؛ أو ارفع `DEMO_RESET_HOURS`.
- سيناريو عرض مقترح (5 دقائق): مدير ← لوحة التحكم ← حضور الموظفين ← الأقساط المتأخرة ← الأعوام الدراسية؛ ثم ولي أمر لترى ما يصل إليه؛ ثم عرض لغة الواجهة والوضع الداكن.

## حدود يجب أن تعرفها
- **الزوار يتشاركون البيانات نفسها.** إن جرّب مديران معاً سيرى كل منهما تغييرات الآخر، وإعادة التهيئة قد تقطع جلسة أحدهم. بيئة معزولة لكل زائر ممكنة لكنها عمل إضافي.
- هذه نسخة للتجربة فقط. لمدرسة اشترت النظام انشر نسخة **منفصلة** بقاعدتها الخاصة وفق `DEPLOY.md` **دون** `SCHOOL_DEMO_MODE`.
- إعادة التهيئة تمسح كل شيء بما فيه المستخدمون الذين أنشأهم الزوار.
